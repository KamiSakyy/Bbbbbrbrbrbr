# Яндекс Браузер 1.0.2 — скачать

**https://github.com/KamiSakyy/Bbbbbrbrbrbr/releases/latest**

Ровно два APK, никаких эмуляторных сборок:

| Файл | Размер | Кому |
|------|--------|------|
| `app-arm64-v8a-release.apk` | 87 МБ | все современные телефоны |
| `app-armeabi-v7a-release.apk` | 84 МБ | старые 32-битные |
| `SHA256SUMS.txt` | — | контрольные суммы |

Установка: скачайте файл прямо на телефон, откройте его, разрешите установку
из неизвестных источников. Android 8.0+ (требование движка GeckoView).

## Что исправлено в 1.0.2

1. **Поиск из адресной строки.** Раньше адрес появлялся только после ответа движка,
   и при задержке казалось, что «ничего не произошло» — теперь адрес и полоса загрузки
   появляются мгновенно. Плюс омнибокс реагирует на любую кнопку клавиатуры
   (Go / Done / Search / Send), а не только на Go.
2. **Ошибки видно.** Вместо чёрного экрана — карточка с причиной (нет сети, DNS, SSL,
   падение процесса) и кнопками «Обновить» / «На главную».
3. **Упавшие вкладки восстанавливаются** автоматически.
4. **Фоновый сервис больше не роняет приложение** (на Android 12+ запуск из `onStop`
   бросал исключение).
5. **Меню → «Диагностика движка»**: видно, поднялся ли GeckoView, идёт ли загрузка,
   была ли первая отрисовка, какая ошибка. Кнопки «Проверить загрузку сайта (ya.ru)»
   и «Скопировать отчёт».

## Если что-то не работает

1. Меню → **Диагностика движка** → «Скопировать отчёт» и пришлите текст.
2. С компьютера: `adb logcat -s YBBrowser` — браузер пишет все события с этим тегом
   (`ENGINE_READY`, `LOAD`, `PAGE_START`, `PAGE_STOP`, `FIRST_PAINT`, `LOAD_ERROR`).

## Что внутри

Движок GeckoView 155 (не Android WebView): собственный рендеринг, SpiderMonkey,
сетевая часть, защита от трекинга. Экономия трафика включена по умолчанию
(~100 рекламных доменов, вырезание трекинговых параметров, без веб-шрифтов).
Тёмная тема везде, поисковик Яндекс, вкладки не закрываются в фоне
(foreground-сервис с уведомлением), состояние вкладок сохраняется.
