# Яндекс Браузер 1.0.1 — релиз готов

**Скачать:** https://github.com/KamiSakyy/Bbbbbrbrbrbr/releases/latest

Подписанные релизные APK собраны GitHub Actions (`Build & Release APK`, run по тегу `v1.0.1`),
прошиты через R8, с сокращёнными ресурсами и сжатыми нативными библиотеками.

## Что скачивать

| Файл | Размер | Кому нужен |
|------|--------|------------|
| `app-arm64-v8a-release.apk` | 87 МБ | почти все телефоны с 2017 года и новее |
| `app-armeabi-v7a-release.apk` | 84 МБ | старые 32-битные устройства |
| `app-x86_64-release.apk` | 92 МБ | эмуляторы, планшеты на Intel |

Ещё в релизе лежит `SHA256SUMS.txt` — контрольные суммы для проверки целостности.

## Установка

1. Скачайте APK прямо на телефон (откройте ссылку в мобильном браузере) или перекиньте файл по USB.
2. Откройте файл в проводнике.
3. Разрешите установку из неизвестных источников для того приложения, из которого открываете файл
   (Chrome / Проводник / Файлы).
4. Готово — в списке приложений появится «Яндекс Браузер» с иконкой «Я».

Android 8.0+ (minSdk 26) — это требование самого движка GeckoView.

## Что внутри

**Движок — GeckoView 155, а не WebView.** Класс `android.webkit.WebView` в проекте не используется
вообще: в APK встроен полноценный движок Mozilla из открытых исходников — свой рендеринг
(`libxul.so`), свой JS-движок SpiderMonkey, свой сетевой стек, своя защита от трекинга.
`libxul.so` и есть те 87 МБ: это целый браузер, а не оболочка над системным компонентом.

**Экономия трафика включена по умолчанию.** Заблокировано ~100 рекламных и аналитических доменов
(собственное расширение `yandex-assistant`), вырезаются рекламные и трекинговые query-параметры,
выключены веб-шрифты в режиме экономии, `preferredColorScheme` переведён на тёмный, включён GPC.
Сломать это можно только вручную: Настройки → Экономия трафика.

**Фоновый режим: вкладки не закрываются.** Foreground-сервис с постоянным уведомлением держит
сессии Gecko живыми. Вышли из браузера, позвонили, вернулись через час — страница там же, без
перезагрузки: состояние каждой вкладки сериализуется во время работы (`onSessionStateChange`).

**Тёмная тема и принудительный тёмный режим.** Интерфейс — чёрный флэт (#000000, панели #141416,
акцент #FC3F1D), без градиентов. На сайтах без тёмной темы скрипт расширения переключает палитру
сам: тёмный фон там, где сайт светлый, картинки и видео не инвертируются.

**Поисковик — Яндекс** (плюс Google, Bing, DuckDuckGo на выбор), русский интерфейс.
Есть быстрый доступ 4×2 с живыми фавиконками, «Яндекс Собеседник» на домашней странице,
вкладки (обычные и приватные), закладки, история, загрузки через системный DownloadManager,
поиск по странице средствами движка, версия для ПК, шэринг и очистка данных.

## Проверено

- CI зелёный: `:app:assembleRelease` с R8, релиз опубликован по тегу.
- Экономия веса: APK уменьшился с 183 МБ до 87 МБ (arm64) за счёт сжатия нативных библиотек
  (`useLegacyPackaging`) — отчёт о составе APK виден в комментарии к PR #1.
- Компиляция: Kotlin 2.4.10 + Compose BOM 2026.09.00, AGP 9.1.1, Gradle 9.3.1, compileSdk 37,
  minSdk 26, R8 с ProGuard-правилами для движка и сервиса.

## Что стоит сделать дальше

1. **Постоянный ключ подписи.** Сейчас CI подписывает APK временным ключом, который создаётся на
   раннере (секретов в репозитории нет). Чтобы обновления ставились поверх предыдущей версии,
   добавьте секреты: `ANDROID_KEYSTORE_BASE64`, `ANDROID_KEYSTORE_PASSWORD`, `ANDROID_KEY_ALIAS`,
   `ANDROID_KEY_PASSWORD` — workflow подхватит их автоматически.
2. **Проверка на живом устройстве.** В песочнице нет Android-устройства, поэтому финальный
   смоук-тест (запуск, вкладки, экономия трафика, уведомление в фоне) нужно сделать у себя.
3. **PR #1** (`arena/01a09ed9-bbbbbrbrbrbr` → `main`) открыт и ждёт вашего решения о мерже:
   https://github.com/KamiSakyy/Bbbbbrbrbrbr/pull/1
