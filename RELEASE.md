# Яндекс Браузер — статус 1.0.2 (проверка в процессе)

> ⚠️ Сборка 1.0.2 ещё не опубликована: GitHub-токен в рабочей среде истёк,
> CI не запускается. Как только доступ восстановят — сборка пойдёт автоматически,
> и релиз опубликуется **только после успешной проверки в эмуляторе**.

## Что исправлено в 1.0.2

1. **Загрузка страниц стала видимой и понятной.**
   Адрес в адресной строке теперь появляется сразу (раньше главный экран ждал
   колбэка движка, поэтому после ввода запроса «ничего не происходило»).
2. **Поиск из адресной строки работает с любой клавиатурой.**
   Омнибокс реагирует на Go / Done / Search / Send, а не только на Go.
3. **Ошибки видно.** Если сайт не открылся (нет сети, DNS, SSL, падение процесса),
   вместо чёрного экрана показывается карточка с объяснением и кнопками
   «Обновить» / «На главную».
4. **Упавшие вкладки восстанавливаются** — сессия переоткрывается сама.
5. **Фоновый сервис больше не роняет приложение.** Раньше он запускался из `onStop`,
   что на Android 12+ бросает `ForegroundServiceStartNotAllowedException`; теперь
   сервис поднимается, пока приложение на переднем плане.
6. **Появился экран «Диагностика движка»** (меню → Диагностика): видно, поднялся ли
   GeckoView, идёт ли загрузка, была ли первая отрисовка, какая ошибка; есть кнопка
   «Проверить загрузку сайта (ya.ru)» и «Скопировать отчёт».
7. **Релиз теперь содержит ровно два APK: arm64-v8a и armeabi-v7a.** Сборка для
   эмулятора (x86_64) осталась только внутри CI — она нужна для автотеста и в релиз
   не попадает.

## Как CI проверяет, что браузер действительно работает

В workflow добавлена отдельная проверка: поднимается Android-эмулятор (API 34),
ставится собранный APK, браузер запускается, открывается сайт по deep link,
затем в адресную строку вводится поисковый запрос. После этого собираются
logcat, скриншот и отчёт. Сборка считается успешной только если в логах есть:

- `ENGINE_READY` — движок Gecko поднялся;
- `PAGE_START` — загрузка страницы началась;
- `PAGE_STOP success=true` или `FIRST_PAINT` — страница загрузилась и отрисовалась;
- нет `FATAL EXCEPTION`.

Публикация релиза (`release` job) запускается только после этой проверки.

## Если что-то не работает у вас

1. Откройте меню → **Диагностика движка** → «Скопировать отчёт» и пришлите текст —
   в нём видно состояние движка и последнюю ошибку.
2. Либо с компьютера: `adb logcat -s YBBrowser` — весь браузер пишет логи с этим тегом.
